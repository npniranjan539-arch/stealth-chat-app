# 📱 Stealth Chat App (WhatsApp Inspired)

A WhatsApp-inspired chat application built using HTML, CSS, and JavaScript. The project simulates real-world messaging behavior and includes a unique Stealth Mode feature that controls message delivery and visibility.

🚀 Features:-

💬 Messaging Features

* Send and receive messages
* Auto reply simulation
* Message timestamps
* Typing indicator
* Online / Last Seen status

 ✅ Message Status

* Single Tick (Sent)
* Double Tick (Delivered)
* Blue Tick (Seen)

 🕵️ Stealth Mode

* Messages remain hidden from receiver
* Only single tick is shown
* No delivery or seen status
* Messages are delivered when Stealth Mode is disabled

🛠 Message Management

* Search messages
* Edit messages
* Delete messages
* Copy messages
* Forward messages
* Pin / Unpin messages
* Message reactions

 🎨 User Experience

* Dark Mode
* Toast notifications
* Date separators
* Auto scrolling
* Empty state screen

📊 Analytics & Storage

* Unread message counter
* Chat statistics
* LocalStorage persistence
* Export chat
* Clear chat

* LocalStorage API
